# 출시 전 기믹·이미지 점검

점검일: 2026-10-15. 대상은 `IMPLEMENTATION_PROMPTS.md`의 8개 항목과 `CLAUDE.md`의 이미지 미생성 기록이다.

## 실시간 연출

현재 `SCENARIO.md`는 실세계 시간 연동을 하나로 제한한다. 로컬 시각 00:00 이상 03:00 미만에 Day 4~5 복도에서 `latenightAlone` 지문을 한 번 표시한다. 이 지문의 표시 여부는 `latenight_shown` 플래그로 저장된다.

기존 코드는 장소 대신 장면 ID에 `_night`가 있는지 검사했다. 그래서 집이나 욕실에서 지문을 먼저 소비하고 실제 복도에서는 놓칠 수 있었다. 현재 화면의 배경 경로로 복도를 확인하도록 수정했다. 앞 장면에서 이어받은 배경도 포함하며 엔딩에는 표시하지 않는다. 이야기 속 점심·밤과 플레이어의 실제 시각은 별도로 판단한다.

3시 ±15분 분기, 디지털 시계 HUD, CAGE 자정 대사는 과거 프롬프트의 제안으로 남아 있다. 현재 설계에는 포함되지 않는다. `getTimeDialogue()`와 `isTimeQuery()`도 호출처가 없는 보조 메서드다. 시간 대사 템플릿은 8개 언어에 있지만 현재 코드베이스에는 연결할 `FreeTalkSystem`이 없다.

## 오디오·인터랙션

설화의 Day 3 밤 경고와 Day 4 거울 속삭임은 `glitch.panSFX` → `GameEngine._handleGlitch()` → `AudioManager.playSFXPanned()`로 이어진다. `sfx_whisper_seolhwa.mp3` 실파일이 있으며 디코딩을 확인한다. 바이노럴 활성 시 pan은 -1, 비활성 시 0이다. 초기 출력 감지와 `devicechange` 감청도 연결되어 있다.

`detectStereoOutput()`은 장치 이름과 출력 채널 수를 참고한다. 스테레오 스피커에서도 활성화될 수 있으며 실제 이어폰 착용 여부를 확정하지 못한다. 자동 검증은 오디오 파일 로드와 코드의 패닝 경로를 확인한다.

타이머 바의 크기·배경색·경고 상태는 `dialogue.css`에 있다. 기존 `review-regressions.spec.js`가 타이머 표시, 메뉴에서 일시 정지, 타이틀로 나간 뒤 콜백 취소를 검증한다.

스탯 공개 장면은 애니메이션 중 HUD 변경을 막고 `stat-revealed` 상태를 유지한다. 브라우저에서 HUD를 갱신한 뒤에도 opacity가 0.5보다 큰지 확인한다. 거울에는 세아의 실제 표정 이미지를 넣고 설화만 제외되는지 검사한다.

모바일 거울은 Chromium의 터치 이벤트로 위에서 아래로 닦는다. Day 4 세로 화면에는 의도된 회전 안내가 있으므로 가로로 회전한 뒤 검사한다. 완료 뒤 캔버스가 사라지고 `_clickLocked`가 해제되는지 확인한다. 모바일 장면의 진동이 `navigator.vibrate()`까지 도달하는지도 검사한다. 시나리오에 쓰인 모든 진동 패턴 이름을 사전과 대조하는 단위 테스트를 추가했다.

관리 패널은 667×375 화면에서 하단 여백 390px 때문에 높이가 14px로 줄어드는 문제가 있었다. 낮은 가로 화면에는 대사창 크기에 맞춰 여백을 줄였다. 피험자 목록을 읽는 긴 지문도 패널과 겹쳤으므로 이 패널이 있을 때만 지문 영역 높이를 제한하고 스크롤을 허용했다. 원문은 유지한다. 1280·1024·768·375·667px 화면에서 패널 경계, 마지막 행 표시, 대사창과의 분리를 검증하고 스크린샷을 확인했다.

## 이미지

`audit-release-assets.cjs`는 `CONFIG.BACKGROUNDS`, `EXPRESSIONS`, `EVIDENCE_IMAGES`, `SUBJECT_FACE_IMAGES`의 모든 유효 경로를 모아 실파일을 열고 픽셀을 디코딩한다. 고유 파일 157개가 통과했고 누락·손상은 0개였다. 항목별 집계는 [JSON 기록](release-assets-2026-10-15.json)에 있다.

배경 85개 키는 파일 81개, 캐릭터 표정 65개 키는 파일 58개를 참조한다. 이전 미완 배경 4개도 모두 존재한다. alias는 같은 실파일을 공유하는 의도된 매핑이며 이미지 누락이 아니다. 기존 `scene-media-audit.spec.js`가 전체 런타임 장면의 이미지 매핑과 파일 존재 여부를 별도로 검사한다.

## 재검증과 기기 점검

- `npm run check`: 문법, 정적 검증, 번역 키, 시나리오 문서 동기화, 단위 테스트.
- `npm run test:e2e`: 새 기믹 테스트와 기존 전체 브라우저 테스트. 반응형 테스트에는 1280·1024·768·375·667px 화면이 포함된다.
- `npm run audit:assets`: 레지스트리 이미지 전체 디코딩. JSON을 갱신하려면 `node scripts/audit-release-assets.cjs docs/qa/release-assets-2026-10-15.json`을 실행한다.

물리 기기에서는 이어폰을 연결·해제하며 설화 속삭임이 왼쪽에서 들리는지 확인한다. 진동을 지원하는 Android에서는 거울 장면의 박동과 추격 장면의 진동을 확인한다. iOS Safari에서는 실제 손가락으로 거울을 닦아 완료되는지 확인한다. 자동 검증 결과를 실제 기기에서의 청취·진동·Safari 검증으로 간주하지 않는다.
