# Search metadata and missing-URL handling — 2026-10-16

## Changes

The game previously replaced each homepage's published search title and
description with short story taglines after initialization. The eight runtime
locale records now use the existing published HTML metadata verbatim. The
homepage HTML remains the source of truth: `npm run seo:sync` updates runtime
metadata and `npm run check:seo` detects drift during local checks and CI.
The eight homepage script URLs have a new cache version, and their sitemap
entries record the actual modification date.

Cloudflare Pages previously returned the home document with status 200 for
nonexistent paths. The Pages middleware now detects this fallback using its
root-home canonical and responds with 404 and `noindex, nofollow`. Its response
body is preserved. GET and HEAD agree. Existing pages, HTML aliases, redirects,
non-HTML responses, source-file protection and original errors keep their
existing behavior.

## Limits and follow-up

This fixes reproducible technical defects; it does not establish the reasons
for the 27 URLs excluded in Search Console. No inaccessible Search Console
data, backlink metrics or keyword volumes were fabricated. Existing canonical,
hreflang, sitemap membership and visible navigation are preserved. Search
ranking and traffic improvements require recrawling and are not guaranteed.

After Google reprocesses the release, compare the same 28-day Search Console
windows by impressions, clicks, page and relevant query. Inspect indexing
exclusions before changing sitemap membership or consolidating landing pages.
